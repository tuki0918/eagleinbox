Eagle Inbox

プライバシーポリシー

施行日： 2026年8月13日

本プライバシーポリシーは、Eagle Inbox（以下「本アプリ」）ならびに その共有機能拡張およびAppleショートカットのアクションを利用する際に、 情報がどのように取り扱われるかを説明するものです。本アプリは、端末から Eagleデスクトップアプリ、またはユーザーが指定したEagle Web API互換の 接続先へコンテンツを直接送信するためのアプリです。

プライバシーの概要

  • 開発者が運営するアップロードサーバーはありません。 ファイル、URL、メタデータは、ユーザーが設定した接続先へ直接送信されます。 Eagle Inboxのサーバーを経由することはありません。
  • 広告、アクセス解析、トラッキングSDKは使用しません。 本アプリは第三者の広告・アクセス解析サービスを使用せず、ほかのアプリや ウェブサイトをまたいでユーザーを追跡しません。
  • 設定は端末内に保存されます。 接続設定と環境設定は端末内に保存され、APIトークンはiOSのKeychainに保存されます。
  • 送信する内容はユーザーが管理します。 写真、ファイル、URLには、ユーザーが選択または共有した場合にのみアクセスし、 アップロードを開始したとき、または設定済みのショートカットを実行したときにのみ送信します。

1. 適用範囲

本ポリシーは、Eagle InboxのiOSアプリ、共有機能拡張、およびAppleショートカットの アクションに適用されます。Eagleデスクトップアプリ、Appleのサービス、追加したURLの ウェブサイト、第三者が運営するEagle Web API互換の接続先には適用されません。 これらには各サービスのプライバシーに関する取り扱いが適用されます。

2. 本アプリが取り扱う情報

利用する機能に応じて、本アプリは以下の情報を端末内で処理し、または選択した接続先へ送信します。

送信するために選択したコンテンツ

本アプリで選択したもの、ほかのアプリから共有したもの、またはEagle Inboxの ショートカットに渡した写真、動画、音声ファイル、PDF、その他の対応ファイルおよびウェブURL。

アップロードのメタデータ

Eagleライブラリにアイテムを作成するために必要なフォルダーの選択、タグ、注釈、 ファイル名、メディア形式およびその他の情報。

接続情報

接続名、ホスト名またはIPアドレス、ポート、HTTPまたはHTTPSの設定、ユーザーが入力した場合の APIトークン、および接続先のEagleライブラリ名。本アプリは、アップロード時のメタデータ選択と 接続先の確認のため、選択した接続先からフォルダー名、タグ、タググループ、ライブラリ情報を取得する場合があります。

端末内のアプリ情報

アプリの環境設定、選択中の接続先、最近選択したメタデータ、Eagle Inbox Proが利用可能かを示す 端末内のキャッシュ。本アプリは、アップロードの準備または実行中に、選択したファイルの一時的な ローカルコピーを作成する場合があります。

URLのプレビュー

ウェブURLを追加すると、AppleのLink Presentationフレームワークがアイコンまたはプレビュー画像を 取得するため、そのウェブサイトへ接続する場合があります。ウェブサイトは独自のプライバシーに関する 取り扱いに従い、IPアドレスなどのネットワーク情報を受け取る場合があります。

開発者が本アプリを通じてこれらの情報を受け取ることはなく、Eagle Inbox用のサーバー上の アカウントまたはデータベースを運営していません。

3. 情報の利用目的

本アプリは、上記の情報を以下の目的にのみ利用します。

  • ユーザーが設定した接続先への接続および接続テスト
  • 接続先のライブラリ、フォルダーおよびタグの表示
  • ユーザーが開始したアップロードの準備、送信、進捗確認および再試行
  • 端末上での設定および選択中の接続先の記憶
  • Appleを通じたEagle Inbox Proの購入確認および復元
  • アップロード結果に関する任意のローカル通知の表示

本アプリは、コンテンツまたは接続情報を、広告、プロファイリング、データ販売、 または人工知能モデルの学習に利用しません。

4. 情報の共有および開示

開発者は、広告目的で個人情報を販売、貸与、共有しません。情報が端末外へ送られるのは、以下の場合に限られます。

  • ユーザーが選択した接続先： コンテンツ、メタデータ、接続リクエスト、および設定されている場合はAPIトークンが、 選択したEagleまたは互換接続先へ送信されます。
  • Appleのサービス： AppleはEagle Inbox Proの購入および利用権に関する情報を処理し、ファイル選択、共有、 プレビュー、通知、ショートカットに使用するシステムフレームワークを提供します。 Appleは独自のプライバシーポリシーに従って情報を取り扱います。
  • ユーザーの操作による場合： コンテンツを選択または共有したとき、接続先を設定したとき、またはショートカットを実行したとき。
  • 法的要請： サポートへの問い合わせなどにより開発者がユーザーから直接情報を受け取った場合、 法令遵守または権利、安全およびセキュリティの保護に合理的に必要な範囲で開示することがあります。

5. 保存、保持および削除

  • 接続情報と環境設定は、ユーザーが変更または削除するまで端末内に保存されます。 APIトークンは通常のアプリ設定ではなくiOSのKeychainに保存されます。
  • 一時アップロードファイルは、アップロードの準備または完了にのみ使用され、不要になった時点で 本アプリにより削除されます。iOSが一時ストレージを管理する場合もあります。
  • 保存済みの接続先を本アプリから削除すると、端末に保存された接続情報とAPIトークンを削除できます。 Keychainの動作はiOSによって管理されるため、Keychain項目を確実に削除したい場合は、 本アプリをアンインストールする前に保存済みの接続先を削除してください。
  • Eagleへ送信済みのコンテンツは、選択した接続先に保存され、その接続先によって管理されます。 削除するには、Eagleライブラリから削除するか、互換接続先の運営者へお問い合わせください。
  • 開発者がアクセス、エクスポートまたは削除できるEagle Inboxのサーバー上のコピーはありません。 ユーザーから送信されたサポートメッセージは、回答、サポート記録の維持、または法的義務の遵守に 合理的に必要な期間のみ保持されます。

6. ネットワークの安全性

Eagleデスクトップアプリへ直接接続する場合、Eagle Inboxは通常、ローカルネットワーク上でHTTPを使用します。 HTTPでは、APIトークン、アップロードするコンテンツ、およびメタデータは通信中に暗号化されません。 Eagle Web APIでは、APIトークンがURLのクエリパラメーターに含まれます。HTTPは信頼できる プライベートネットワークでのみ使用し、暗号化されていないEagle APIをインターネットへ公開したり、 公衆Wi-Fiから使用したりしないでください。

本アプリは、互換性のあるカスタム接続先へのHTTPS接続にも対応しています。HTTPS接続では、端末が 信頼する証明書を使用する必要があります。保存または通信の方法に完全な安全性を保証することはできず、 設定した接続先の安全性を確保する責任はユーザーにあります。

7. Appleのサービスと権限

本アプリはEagleへ接続するためにローカルネットワークへのアクセスを求める場合があり、ユーザーが選択した コンテンツを扱うためにシステムの選択画面または共有シートを使用します。通知は任意であり、アップロード結果の お知らせにのみ使用されます。権限はiOSの「設定」で管理できます。

Eagle Inbox ProはAppleが処理する非消耗型のアプリ内課金です。開発者が支払いカードの完全な情報を 受け取ることはありません。本アプリはPro機能の解除および購入の復元のため、StoreKitから製品情報と 利用権の状態を受け取ります。Appleによるデータの取り扱いについては、 Appleのプライバシーポリシーをご覧ください。

8. このウェブサイト

このプライバシーポリシーページはCookieを設定せず、広告またはアクセス解析のコードを含みません。

9. お子様のプライバシー

Eagle Inboxは13歳未満のお子様を対象としておらず、開発者が本アプリを通じてお子様の個人情報を 意図的に収集することはありません。

10. 本ポリシーの変更

本プライバシーポリシーは、本アプリまたは適用される要件の変更を反映するため更新される場合があります。 更新後のポリシーはこのURLに掲載し、ページ上部の施行日を改定します。重要な変更については、必要に応じて 適切な方法でお知らせします。

11. お問い合わせ

Eagle Inboxに関するご質問またはご要望は、 GitHub Issuesから 開発者へお問い合わせください。

APIトークン、非公開URL、個人ファイル、その他の機密情報を記載しないでください。
